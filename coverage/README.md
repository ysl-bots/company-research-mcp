각 회사·항목별로 접수번호, 원문 위치, 저장값과 응답 위치를 대조해 수집 확인·누락 확인·원문 미공시·미검증을 기록한다. 합의된 필수 범위에서 확인한 누락을 먼저 보완하고 같은 원문으로 재확인한 뒤 평가 브랜치에서 정적 검사와 Judge 평가를 진행한다.

공통 필수 범위는 주력 사업·제품과 부문별 매출 구성, 시장 여건·경쟁 요소, 연구개발·투자 방향, 최근 3개년 매출·영업이익이다. 수집 보완은 기업 고유 소재와 개인 경험을 연결하는 데 필요한 공시 근거를 대상으로 한다.
